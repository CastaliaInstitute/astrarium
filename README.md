# Astrarium

A bedtime star projector and astronomy sleep companion for children, built on a HY300 projector. Evening guided constellation tours with audio lessons; at midnight, a silent 3D faster-than-light journey across the night sky to the featured constellation's farthest star, home by dawn. Milky Way, textured planet globes, satellites — controlled from a parent PWA.

Part of the [Castalia Institute](https://castalia.institute) Atlas projector family.

Live at https://astrarium.castalia.institute
