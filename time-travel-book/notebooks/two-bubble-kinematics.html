Two-bubble CTC: computable kinematics#

This chapter reproduces the symmetric closure calculation discussed by Shoshany and Snodgrass and extends it algebraically to a nonzero spatial endpoint. The first model is the paper’s symmetric benchmark. The second is a flat 1+1 kinematic extension only; it is not the paper’s compact-support metric retargeted to Bethlehem.

Let \(U=u/c\) be the relative inertial-frame speed and \(V>1\) the common average bubble-separation speed in each leg’s own asymptotic frame. The symmetric closed-loop finish time satisfies

\[ \frac{T_{\mathrm{finish}}}{T_2} =\frac{2V-U(1+V^2)}{V-U}, \qquad U>U_{\mathrm{crit}}=\frac{2V}{1+V^2} \]

for a return to the initial spatial point before departure. For their smooth-profile example, \(V=U[1+\omega(\alpha-1)/4]\). The plotted “speed” is the average separation rate of a warp-supported region; the passenger worldline remains timelike.

For a target endpoint \(C=(t_C,z_C)\), the flat 1+1 relation is

\[ t_C=A T+B z_C,\quad A=\frac{2V-U(1+V^2)}{V-U},\quad B=\frac{VU-1}{V-U}. \]

The scenario below uses a roughly 2,031-year lookback as a scale representative of 6 BCE to 2026 CE; it does not claim an exact Star date. It projects constant 230 km/s solar motion along one chosen axis. This is not the reconstructed Earth/Magi endpoint vector, a celestial ephemeris, or a solved A.R.G.O. route. It exposes how strongly this simple endpoint model’s spatial scale grows for an ancient destination.

import numpy as np
import plotly.graph_objects as go
from IPython.display import HTML, display

# Parameters of the paper's explicit smooth-profile example.
U0, alpha0, omega0 = 0.75, 10.0, 0.95
lookback_years = 2031.0  # Illustrative scale only; the source narrative gives no exact year.
solar_speed_km_s = 230.0
seconds_per_year = 365.25 * 24 * 3600
km_per_lightyear = 299_792.458 * seconds_per_year
solar_motion_ly_per_year = solar_speed_km_s * seconds_per_year / km_per_lightyear
z_target_ly = solar_motion_ly_per_year * lookback_years

def symmetric_ctc(U, V):
    return (2 * V - U * (1 + V**2)) / (V - U), 2 * V / (1 + V**2)

def endpoint_coefficients(U, V):
    return (2 * V - U * (1 + V**2)) / (V - U), (V * U - 1) / (V - U)

V0 = U0 * (1 + omega0 * (alpha0 - 1) / 4)
A0, B0 = endpoint_coefficients(U0, V0)
T_first = (-lookback_years - B0 * z_target_ly) / A0
D_first = V0 * T_first
print(f"V = {V0:.6f} c")
print(f"Ucrit = {2*V0/(1+V0**2):.8f}; chosen U = {U0:.3f}")
print(f"Tfinish/T2 = {A0:.8f}")
print(f"Illustrative target displacement = {z_target_ly:.3f} ly")
print(f"Flat endpoint estimate: T2 = {T_first:,.1f} y, first-leg separation = {D_first:,.1f} ly")

Retargeting gap#

The calculated displacement assumes constant 230 km/s solar motion aligned with one selected axis. It omits Earth’s orbital and rotational state, the observer’s terrestrial location, historical Earth-rotation uncertainty, the undefined exact event epoch, and any measured A.R.G.O. trajectory. Changing the endpoint shifts this flat estimate; it does not move the finite support profiles, recompute the lapse, or solve the geodesic equations in the published spacetime. A physical mission still needs a full CTG intersecting a declared Bethlehem-region event and the relevant photon worldlines, closing at departure and passing finite-hull and field-support checks. The Star narrative alone is too sparse to determine that endpoint. See the candidate review.
