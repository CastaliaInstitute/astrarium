Model boundary

With ρ′/ρ = 1,000 and Δχ = 0, five boost images lie inside the receiver's past light cone. For a unit point source in the 1+1D massless wave equation, each interior-cone Green term has the same constant value, so the Green-function value at that receiver event is five times the one-image value. A finite waveform is integrated against each image's retarded Green function; in 1+1D the interior-cone support produces tails, so the terms are not five sharp arrivals. Neither case is an energy gain or a drive-power prediction. The path count grows without bound as ρ approaches the chronology horizon alongside a source sequence with ρ′/ρ → ∞.

This image sum is not a propagator through the CTC region. There, a source's timelike quotient copies can wind around the loop repeatedly; the naïve retarded image sum is not guaranteed to converge or define a unique field. Do not interpret the path count as real drive gain or as a solved A.R.G.O. signal.
